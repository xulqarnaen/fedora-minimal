# Omarchy user configuration backup

This directory contains the user-level Omarchy configuration files backed up
from `~/.config`. Files that are generated, machine-specific runtime state,
sample hooks, and backup snapshots are intentionally excluded.

To restore, copy the contents of this directory into `~/.config` while logged
into the matching Omarchy installation. Review `hypr/monitors.lua` first if
restoring to different hardware.
